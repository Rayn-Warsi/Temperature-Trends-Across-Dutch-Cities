# Temperature Trends Across Dutch Cities

Statistical analysis of temperature patterns across Dutch cities using R.

## Overview

This project investigates temperature differences and trends across Dutch cities using descriptive statistics, sampling, distributional analysis, and regression techniques.

## Methods

- Descriptive and comparative analysis
- Sampling and statistical inference
- Normality testing
- Regression analysis
- Interpretation of temperature trends

## Tools

`R` · Statistics · Regression · Data Analysis
